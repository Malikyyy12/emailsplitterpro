# 📧 Email Splitter Pro

Email Splitter Pro is a desktop application built with Python and CustomTkinter that allows users to split large email lists into multiple smaller files quickly and efficiently.

---

## Features

- 📂 Import TXT and CSV email lists
- ⚡ Fast email splitting
- 📊 Progress bar during processing
- 📁 Automatically creates output files
- 💻 Simple graphical user interface
- 🖥️ Cross-platform (Windows & macOS)

## Installation

Clone this repository:

```bash
git clone https://github.com/Malikyyy12/emailsplitterpro.git
```

Install the required package:

```bash
pip install customtkinter
```

Run the application:

```bash
python denomination.py
```
